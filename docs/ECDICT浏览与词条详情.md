# ECDICT 浏览与词条详情

## 第一阶段范围

- 公开访问 `/dicts/ecdict`，以 ECDICT 为唯一来源；详情位于 `/dicts/ecdict/:id`，标识为来源词条 UUID，不按规范词形合并记录。
- 搜索匹配忽略大小写的词条或词形前缀；`%`、`_` 等按字面处理，不做任意子串、拼写纠错或 AI 搜索。空搜索浏览全部词条。多个来源词条可以匹配同一词形。
- 形式筛选按优先级划分为：含空白的词组；首尾均为连字符的归入“其他”；以连字符开头的后缀（如 `-able`）；以连字符结尾的前缀（如 `un-`）；内部包含连字符的复合词；仅含字母的纯单词；其余条目归入“其他”。例如 `apple -pie` 是词组，`address-book` 是复合词，带数字或撇号且不符合其他规则的词条属于“其他”。分类只是拼写启发式，不代表权威词性或词根；筛选条件写入 URL，搜索和切换分类重置游标。历史 `category=affix` 链接仍展示前缀和后缀。
- “Dotted abbreviations” 是可与上述分类重叠的拼写筛选：词条任意位置的点两侧均为字母或数字，且至少一侧为字母，例如 `A.B.G.`、`A.1`。`6.2` 和 `...` 不匹配；带匹配片段的词组仍可同时在词组筛选中找到。该规则不保证匹配项确实是缩写，也不识别所有缩写。
- 列表按词条小写形式、原词排序，采用双向游标分页，每页 10 条；搜索词和游标写入 URL，详情返回链接保留列表状态。无总页数，避免请求时全表统计。
- 桌面端左侧列表、右侧详情，窄屏详情以可关闭面板呈现；详情直链可分享。分页按钮分居两侧并始终显示，不可用时禁用。支持 `/` 聚焦搜索、`j/k` 或上下方向键选择词条、左右方向键翻页、`f/l` 首末项、`?` 查看快捷键以及 `Esc` 退出输入或关闭面板；输入时暂停导航快捷键，点击快捷键指南背景可关闭指南。
- 详情展示可用的原始中文和英文释义、音标、词性、标签、词频和已导入的相关词形；不虚构例句、音频或权威难度。注明来源和该词条的版本。
- 显示最近一次成功导入记录的行数及版本，明确这是该次处理的行数，不等同当前数据库词条总数或字段覆盖率。未有导入记录时明确提示。字段覆盖统计留待定义并离线计算。
- 登录用户可保存到现有个人生词本；匿名用户先登录并返回详情，需再次点击保存。按现有用户和规范词目去重，已保存词条的笔记和快照不被覆盖。详情查询当前用户的收藏状态，已收藏时直接链接到生词本对应条目；状态读取失败时明确提示，不假装未收藏。

## 数据和查询边界

浏览查询单独放在 ECDICT 查询模块，为词条及词形前缀查询增加 pattern 索引，并为形式分类增加表达式索引。两路候选分别按相同游标顺序获取一页加一条，再在数据库中合并去重和排序。以稳定的 `(word_lc, word)` 游标分页；导入期间数据变化可能使相邻页面变化，游标不表示版本快照。

不修改现有插件 `lookup` 和响应，不将 ECDICT 的字段当作未来所有词典的通用模型。当前 `word` 全局唯一及分批覆盖导入并非多来源或完整版本快照方案；第二个词典接入时另行设计来源存储和聚合。

数据来源为 [ECDICT](https://github.com/skywind3000/ECDICT)，该仓库包含 MIT 许可及版权声明。部署前仍须核实数据组成、展示和再分发的权利，并满足适用的归属和许可条件；仓库许可本身不能证明所有数据内容的权利已清理。

## 失败与验证

无效搜索、分类、游标、词条 ID 和不可用数据应明确提示，不将错误伪装成空结果；空查询结果与数据库异常区分。测试公开访问、直接链接、前缀与词形搜索、分类、去重、双向分页、缺失字段、登录返回、用户隔离、重复收藏、无数据及插件兼容。保持应用的 `mix precommit` 验证。
